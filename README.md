# JSON Schema Toolkit

Understand JSON instantly inside VSCode.

## ✨ Features

- 🔍 Hover preview for JSON
- ⚡ Generate TypeScript types
- 🧩 Generate Zod schemas
- ⚠ Detect shape problems (missing / inconsistent fields)

## 🚀 Usage

### Hover Preview

Hover over JSON or JS objects to see:

- structure explanation
- detected issues
- inferred types

### Generate Types

1. Select JSON
2. Right click
3. Click **"Generate TypeScript + Zod"**

## 🧪 Example

```json
{
  "users": [{ "name": "alex" }, { "age": 30 }]
}
```
