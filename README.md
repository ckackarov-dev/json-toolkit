# JSON Toolkit

Understand any API instantly — without digging through JSON.

## ⚡ Why this exists

Working with API responses is slow and error-prone:
- inconsistent data shapes
- hidden nulls
- missing fields
- unexpected types

👉 JSON Toolkit shows you everything instantly — before it breaks your UI.

---

## ✨ What you get

- 🧠 Instant API understanding (hover any JSON)
- ⚠ Detect shape problems (missing / inconsistent fields)
- 📦 Generate TypeScript types
- 🛡 Generate Zod schemas
- 💡 Clear explanation of your data structure

---

## 🚀 Usage

### Hover any JSON

Just hover over JSON or JS objects and instantly see:
- structure explanation
- detected issues
- inferred types

---

### Generate Types + Zod

1. Select JSON
2. Right click
3. Click **"Generate TypeScript + Zod"**
